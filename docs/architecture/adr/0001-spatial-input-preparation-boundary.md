# Prepare spatial inputs for a separate value-table model

Status: accepted  
Recorded: 2026-10-26

The external use case needs repeatable forest evidence for comparing management pathways, while the procurement explicitly separates the simultaneous-equation model from input preparation. This prototype therefore retrieves and classifies spatial evidence and exports descriptive indicators, leaving scenario impacts, management prescriptions and legal harvesting determinations outside its boundary. This avoids embedding an unverified impact model or presenting sensitivity tiers as complete scenarios; [project context](../../project-context.md) preserves the source material and the prototype's independent status.

The output contract is defined in the [calculation reference](../calculations.md) and [functional scope](../../specs/README.md#product-purpose-and-scope).
